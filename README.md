# Hi, I'm Kyle Tranfaglia 👋

I'm the **Co-Founder & Lead Software Engineer at Pitchfire**, an AI-powered platform for startups and investment teams. As its sole engineer, I own the platform end to end: architecture, the React/TypeScript and Node.js stack, PostgreSQL data modeling, AI systems, infrastructure and production operations.
